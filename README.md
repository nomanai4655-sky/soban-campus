# The Educators (Soban Campus) - Web Application

Python Flask web application for **The Educators (Soban Campus)** in Multan, Pakistan.

## Deployment on Vercel
1. Push this repository to GitHub.
2. Import the repository into your Vercel Dashboard.
3. Vercel automatically detects `vercel.json` and builds the Python project.
4. Set optional environment variables:
   - `ADMIN_USERNAME`: Custom admin login username (default: `admin`)
   - `ADMIN_PASSWORD`: Custom admin login password (default: `soban123`)
